# Autoria – Otomobil Tanıtım Sitesi

## Proje Hakkında

Bu proje, lise eğitimim sırasında web geliştirme alanında
kendimi geliştirmek amacıyla hazırladığım temel seviyede
bir otomobil tanıtım sitesi çalışmasıdır.

Projede BMW, Mercedes-Benz, Audi ve Toyota gibi otomobil
markalarına ait tanıtım sayfaları bulunmaktadır.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## Projenin Amacı

HTML, CSS ve JavaScript konularında öğrendiğim temel
bilgileri uygulamak ve web geliştirme alanındaki
becerilerimi geliştirmek.
